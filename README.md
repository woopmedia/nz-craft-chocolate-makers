# New Zealand Craft Chocolate Makers (October 2026)

A list of New Zealand craft chocolate makers profiled by The Chocolate Bar, with location, website, founding year and founders, as published on each maker's profile page in October 2026.

Source: https://thechocolatebar.nz/makers/

## Columns
- maker: trading name
- location: town or region as given on the profile
- website: maker's official website
- founded: year founded, blank where not confirmed
- founders: founders named on the profile
- profile_url: the full profile on The Chocolate Bar
- profile_updated: date the profile was last checked

## Selection
Makers are bean-to-bar producers who roast, grind and temper their own cacao, can name the cacao origin, and keep short ingredient lists (see https://thechocolatebar.nz/about/).
